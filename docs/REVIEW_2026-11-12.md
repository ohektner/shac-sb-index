# Leakage and soundness review, 2026-11-12

A read of the model and evaluation code by the lead, at commit `571a7db`. Nothing was fixed; this is the list for whoever builds next. No real-data scorecard was run and no number against a line was computed. The local check passed before the review (`uv run pytest -q`: 297 passed, 5 skipped).

Read: `src/shac/model/margin.py`, `sql/model/features.sql`, every file in `sql/scorecard/`, `src/shac/scorecard/run.py`, `sql/tables/game_history.sql`, `sql/tables/closing_lines.sql`, `src/shac/tables/history.py`, `src/shac/ledger/writer.py`, `tests/test_ledger_append_only.py`, `.github/workflows/ci.yml`, and the test lists of `test_no_leakage.py`, `test_margin_model.py`, `test_scorecard.py`.

## Verdict

**No leak found in the backtest path.** Ratings are chosen strictly before tip from one file per game; the model and the baseline learn only from earlier seasons and never from 2020-21; no feature reads a score or a line; inputs were chosen on the three train-only seasons. Each of these has a test. **No mismatch with PREREGISTRATION.md was found** that isn't already covered by a dated DECISIONS.md entry.

The problems are on the live side (the ledger's protection, and how a live "close" is measured), plus a few places where a number could read better or cleaner than it is.

## What was checked and is sound

- **As-of join.** `game_history.sql:26-27` uses `g.tip_at > f.as_of`, strict, within the season, one file for both teams, no fallback to an older file.
- **Walk-forward.** `baseline_predictions.sql:30-37` and `margin.py:74-81` both take seasons strictly before the test season and drop 2020-21. `seasons.sql` is the single list.
- **Labels and benchmarks never feed a prediction.** `features.sql` reads no score or line; `build_features` joins the label on afterwards. Tests blank every score and line and check that nothing moves.
- **Same games for both predictors.** `scored_games.sql:33-40`.
- **Sides and signs.** ATS (`side_close × (home_margin + close_home_spread)`) and CLV (`side_open × (close_margin − open_margin)`) match PREREGISTRATION.md and ARCHITECTURE.md.
- **Pushes** are out of the win %, the Brier score and the reliability table.
- **Input selection** used only 2019, 2020 and 2022, by error against final scores, with the rule written first.
